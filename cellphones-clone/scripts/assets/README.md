# Legacy asset/data helper scripts

These scripts were used while replacing mocked CellphoneS images and URLs during early clone work.

- Run them from `cellphones-clone/` or from this folder; paths are resolved to the project root.
- Raw captured files live in `cellphones-clone/data/legacy/`.
- The active app code lives in `cellphones-clone/src/`; these helpers are not part of the Vite build.
