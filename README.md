# E-commerce Recommendation Chatbot

AI chatbot hỗ trợ gợi ý sản phẩm thương mại điện tử bằng hình ảnh và ngôn ngữ tự nhiên.

## Giới thiệu

Dự án sử dụng YOLOv8 và Gemini API để:
- Nhận diện sản phẩm từ hình ảnh
- Gợi ý sản phẩm thông minh
- Hỗ trợ chatbot AI thương mại điện tử

## Công nghệ sử dụng

- Python
- Flask
- YOLOv8
- Gemini API
- OpenCV

## Chức năng

- Upload ảnh sản phẩm
- Nhận diện đối tượng
- Chatbot AI
- Gợi ý sản phẩm

## Cài đặt

```bash
pip install -r requirements.txt
python app.py
